## Pixel art, characters, environments, UI

All original, written as React/SVG code in `src/strokecode/` (characters, environments, components).
No third-party sprites, images or footage. The football on the TV is abstract original pixel animation (no broadcast).
The brain CT image is a **schematic illustration** drawn in code (`BrainIllustration`), labelled on screen as an illustration, not patient data.
The reference video was used only for style study; no frames, characters or assets were copied.

## Music and sound effects

All audio is **synthesised from scratch** (oscillators, filtered noise, envelopes, algorithmic reverb) by
`scripts/generate_sfx.py`, `scripts/generate_strokecode_audio.py` and `scripts/generate_strokecode_music.py`. No samples, no vocals, no speech, no TTS.

| Score stem | Description |
| --- | --- |
| `public/sc/music/drums.mp3` | Score stem: kick (incl. heartbeat-style double kicks), claps, hats, snare rolls — 127.2 BPM, 120 s |
| `public/sc/music/bass.mp3` | Score stem: sidechained rolling bass pulses |
| `public/sc/music/synths.mp3` | Score stem: supersaw chords, 16th arps, lead hook |
| `public/sc/music/fx.mp3` | Score stem: risers, crashes, impacts (peak on CODE STROKE ACTIVATED) |

The score is generated by `scripts/generate_strokecode_music.py` (original, no samples, no vocals). It is free to
publish on social media. The older cinematic cues (`warm`, `hospital`, `resolve`, `tension`) remain in the repository
but are no longer used by `StrokeCode`.
