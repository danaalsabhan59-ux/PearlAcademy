# فيديو توعوي: السكتة الدماغية — كل دقيقة مهمة

فيديو قصير بأسلوب **Pixel Art** مبني بـ [Remotion](https://www.remotion.dev)، مع أصوات عربية سعودية مولّدة بـ **Microsoft Edge TTS**،
ومؤثرات صوتية وموسيقى مُركّبة برمجيًا (أصلية بالكامل، لا تحتاج أي ترخيص).

**القصة:** أب وابنه يشاهدان مباراة → الأب تظهر عليه أعراض سكتة دماغية ويسقط الفنجان → الراوي يشرح العلامات
(الوجه، الذراعان، الكلام، الوقت) → الابن يتصل بالإسعاف 997 → وصول الإسعاف → رسالة الختام.

---

## المتطلبات

| الأداة | الاستخدام |
| --- | --- |
| Node.js 20+ | Remotion (المعاينة والتصدير) |
| Python 3.9+ و `pip install edge-tts` | توليد الأصوات |
| ffmpeg (اختياري) | تُستخدم نسخة Remotion المدمجة إن لم يكن مثبتًا |
| `pip install numpy` (اختياري) | فقط لإعادة توليد المؤثرات والموسيقى |

```bash
npm i
pip install edge-tts
```

## خطوات العمل

```bash
npm run voices:audition   # 1) عيّنات لتجربة صوت HamedNeural بسرعات ونبرات مختلفة → public/audio/auditions/
npm run voices            # 2) توليد كل جملة في ملف MP3 منفصل → public/audio/voices/<id>.mp3
npm run check:audio       # 3) اختبار كل الأصوات (موجودة، غير صامتة، ومطابقة للنص الحالي)
npm run preview           # 4) معاينة في المتصفح (Remotion Studio) على http://localhost:3000
npm run render            # 5) تصدير MP4 نهائي → out/stroke-awareness.mp4
```

- `npm run voices` يولّد فقط الجمل الجديدة أو التي تغيّر نصها أو إعداداتها. استخدم `npm run voices:force` لإعادة الكل،
  أو `python3 scripts/generate_voices.py --only m1,m4` لجمل محددة.
- إذا فشل توليد أي جملة، يتوقف السكربت ويذكر الجمل الفاشلة **ولا يُنشئ أي ملف صامت**.
- `npm run render` يشغّل `check:audio` أولًا، ولن يبدأ التصدير إذا كان أي صوت ناقصًا أو قديمًا أو صامتًا.
  كذلك ترفض الـ composition نفسها الرندر إذا كانت الأصوات غير مولّدة.

## تعديل الحوارات والتوقيتات — `src/data/dialogue.json`

هذا الملف هو المصدر الوحيد لكل شيء:

- **`characters`**: الاسم، اللون، الصوت (`voice`)، السرعة (`rate`)، النبرة (`pitch`) لكل شخصية.
- **`scenes[].lines[]`**: كل جملة لها `id` و`speaker` و`text` (ما يُنطق) و`display` اختياري (ما يظهر على الشاشة، مثل `997`
  بدل "تسعة تسعة سبعة")، و`pauseBefore` (ثوانٍ من الصمت قبلها). يمكن تجاوز `rate`/`pitch` لجملة معيّنة (مثل كلام الأب المتثاقل).
- **`sfx`**: المؤثرات الصوتية، مربوطة بالحوار عبر "مراسٍ" بدل أوقات ثابتة:
  `{"line": "m4", "edge": "end", "offset": 0.15}` = بعد نهاية الجملة m4 بـ 0.15 ثانية.
- **`music.tensionSections`**: المقاطع التي ترتفع فيها موسيقى التوتر.
- **`ducking`**: مستوى خفض الموسيقى أثناء الكلام (`level`) وسرعة الخفض والرجوع (`attack` / `release`).
- **`visualEvents`**: لحظات الحركة (سقوط الفنجان، ميلان الوجه، سقوط الذراع، وصول الإسعاف…)، وهي أيضًا مربوطة بالحوار.

**لماذا المراسي؟** مدة كل جملة تأتي من ملف الصوت الحقيقي (`src/data/voices.generated.json`)، فإذا عدّلت جملة وأعدت توليدها
تتحرك كل الحركات والمؤثرات والترجمة معها تلقائيًا دون تعديل أي توقيت يدويًا.

## المزامنة

- **مدة الفيديو** = مجموع مدد الأصوات الفعلية + الوقفات (`src/timeline.ts`).
- **حركة الفم** تعتمد على توقيت الكلمات (WordBoundary) من Edge TTS، فينغلق الفم بين الكلمات.
- **الترجمة** تُبرز الكلمات المنطوقة تدريجيًا.
- **نبضات القلب** تتزامن مع وميض أحمر على حواف الشاشة بنفس الإيقاع (84 نبضة/دقيقة).
- **صفارة الإسعاف** تتزامن مع أضواء حمراء/زرقاء في النافذة قبل الوصول.

## الصوت

| الملف | الوصف |
| --- | --- |
| `audio/voices/*.mp3` | جملة لكل ملف — Edge TTS + تنظيف وتوحيد مستوى الصوت (loudnorm −16 LUFS) |
| `audio/sfx/crowd-loop.mp3` | جمهور مباراة (هتاف، تصفيق، صافرة حكم) |

| `audio/sfx/cup-crash.mp3` | سقوط وانكسار فنجان القهوة |

| `audio/sfx/siren.mp3` | صفارة إسعاف تقترب |
| `audio/music/calm-pad.mp3` | موسيقى سينمائية هادئة (ري صغير) |
| `audio/music/tension.mp3` | طبقة توتر بنفس المقام، تُمزج فوق الهادئة في لحظات التوتر |

## الأصوات المختارة

| الشخصية | الصوت | الإعدادات |
| --- | --- | --- |
| الأب | ar-SA-HamedNeural | rate −8%، pitch −6Hz (دافئ وأكبر سنًا) |
| الراوي | ar-SA-HamedNeural | rate −10%، pitch −2Hz (هادئ وواضح) |
| المسعف | ar-SA-HamedNeural | rate +2%، pitch +10Hz (مختلف عن الأب والراوي) |
| الابن | ar-SA-ZariyahNeural | rate +4% (أقرب لصوت طفل؛ لا يوجد صوت ولد سعودي في Edge TTS) |

اللهجة السعودية لا تتوفر إلا بصوتين في Edge TTS (حامد وزارية)، لذلك تُميَّز الشخصيات بالسرعة والنبرة.
إذا أردت تمييز المسعف أكثر، جرّب البدائل الخليجية في `voices:audition` (`ar-KW-FahedNeural` أو `ar-AE-HamdanNeural`).

**نصائح لجعل الكلام طبيعيًا:** الفواصل والنقاط تصنع وقفات طبيعية، وعلامات الحذف (…) تبطئ الإيقاع. ضع التشكيل على الكلمات
التي يُخطئ فيها النطق فقط (مثل "يُبَه")، واكتب الأرقام بالحروف في `text` واتركها أرقامًا في `display`.
