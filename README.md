# Pearl Academy 

Pearl Academy is an AI-powered educational platform for building interactive learning websites.

The project focuses on creating modern educational experiences for both K–12 and medical education.

One of the primary goals is to develop high-quality interactive educational websites in Arabic, as there is currently a shortage of modern Arabic educational web resources for schools. The platform aims to make learning more engaging through interactive lessons, gamification, and browser-based educational tools.

## Areas of Focus
- Arabic K–12 educational websites
- Medical education websites
- Evidence-based clinical learning resources
- Interactive HTML, CSS, and JavaScript applications
